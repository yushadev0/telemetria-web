# public/assets/

Yerel bundle'lanan statik görseller (new-client.md §2, §10).

Şu an mevcut:

- `favicon.png` — sekme ikonu

Sonraki fazlarda buraya eklenecek (§10 kararı: **yerel bundle + eksikte gömülü SVG placeholder**):

- `tracks/*.png` — F1 pist siluetleri ve AC harita katmanı
- `drivers/*.png` — pilot fotoğrafları (`{driver_code}.png`)
- `logo` / wordmark — `telemetria_text_{tr,en}` yerine tek SVG wordmark (`F1Mark` + CSS)

Kaynak eski görseller: `telemetria-client/assets/` ve `https://yusa.app/assets/...`
(uzak klasör garanti değil — bu yüzden yerelleştiriliyor).
